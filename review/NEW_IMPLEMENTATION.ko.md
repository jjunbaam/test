# 새 구현의 범위와 검증 상태

- 대상 설정: PR=master, R=2025_ES5_Release_버전_분기. 개발 Branch는 실제 GitLab 목록에서 사용자가 선택한다.
- 기존 파일은 비교 자료로 유지하고 새 `portal/` 패키지 및 실행 스크립트를 추가했다. 원본의 분석 함수와 토큰을 사용하지 않는다.
- 원격에 쓰지 않는 Git index 적용 시뮬레이션, 대상별 정적 화면 추적, SHA 고정 Sourcegraph 검색, 사내 Pi 구조화 응답, 분석/검증 기록 저장을 구현했다.
- 메뉴 카탈로그가 없어도 실제 소스의 화면 제목은 찾을 수 있다. 실제 메뉴 계층을 확정하지 못하면 미확인으로 표시한다.
- 단일 부모 커밋의 변경 적용만 지원한다. 조직의 실제 merge/cherry-pick/수동 반영 방식은 아직 미확인이다.
- 정적 참조 탐색은 메서드/분기/런타임 전체를 해석하지 않는다. 실제 DLPCenter에 대한 화면 추적 정확도와 결함 예측 품질은 미검증이다.
- 외부 개발 환경에서 Python 테스트 24개 통과: 실제 임시 Git 저장소 적용/충돌/중복/대상별 화면 차이, 한글 브랜치 fetch, 복수 화면, i18n 제목, 버전별 카탈로그, Sourcegraph SHA 필터, Pi 모의 CLI 프로세스, AI 근거 검사, HTTP API와 검증 기록.
- JavaScript 구문 검사와 실제 Uvicorn 서버의 첫 화면/설정 API HTTP 검증 통과. 실제 Windows/PowerShell 설치 실행, Pi 0.81.1 실응답, 사내 GitLab/Sourcegraph 통합 및 브라우저 화면 조작은 미검증이다.
- 사내 첫 실행: README의 설치 → 연결 검사 → 실제 Branch/커밋 선택 → PR/R 분석 → 알려진 화면과 비교. 이 절차로 남은 환경 차이를 식별해야 한다.
